
# Paradise Nursery Shopping Application

## Repository Name

**e-plantShopping**

## Project Overview

Paradise Nursery is a responsive React-based shopping application for browsing and purchasing houseplants online. The application provides users with an attractive landing page, a categorized plant listing, and a dynamic shopping cart.

Users can browse different varieties of houseplants, view their names, descriptions, images, and prices, and add plants to their shopping cart. The shopping cart allows users to manage quantities, remove products, view individual item totals, and calculate the overall cost of their selected plants.

## Main Features

* Responsive Paradise Nursery landing page
* Company information and introduction
* Navigation between Home, Plants, and Cart pages
* Categorized houseplant listings
* Plant images, names, descriptions, and prices
* Add to Cart functionality
* Dynamic shopping cart quantity
* Increase and decrease product quantities
* Remove products from the cart
* Automatic calculation of total cart cost
* Continue Shopping functionality
* Checkout button with a Coming Soon message
* Redux Toolkit for shopping cart state management
